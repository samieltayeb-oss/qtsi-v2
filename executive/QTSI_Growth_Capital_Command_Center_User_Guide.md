# QTSI Growth Capital Command Center™
## Executive User Guide

Welcome to the QTSI Growth Capital Command Center. This portal is a disciplined execution engine designed exclusively to help QTSI, as an early-stage innovation company, secure non-dilutive funding and prepare for growth capital opportunities.

---

### 1. How to Access the Portal
1. Navigate to: [https://qtsi.ca/executive/](https://qtsi.ca/executive/)
2. You will be prompted for a password. This is a single, shared executive password (currently set to your configured secure phrase).
3. The session will keep you logged in securely for 7 days on your device.

### 2. What to Review First (The Daily Routine)
When you log in, your attention should go immediately to the top of the dashboard:
- **🎯 This Week's Executive Priorities:** This tells you the exact 1-2 actions you need to take *today*. Do not look at anything else until the "Execute Now" item is completed.
- **Next Funding Milestone:** The single most important traction event you are driving toward (e.g., *Obtain 2 Pilot LOIs*). 

### 3. How to Use the Readiness Scores
The **Innovation Readiness Score** (e.g., 23%) is an internal planning assessment. It is not an official score used by government agencies. Use this to identify weak points in your execution. For example, if "Customer Validation" is at 40%, you must prioritize securing pilot customers before applying to scaling grants.

### 4. Navigating Funding Opportunities
The portal aggressively separates reality from noise:
- **🚀 Immediate Funding Opportunities:** These are the grants (like IRAP) that QTSI is eligible for *today*. Expand these accordions to see the exact steps to apply.
- **Future Opportunities:** These are listed below to keep you focused. They explicitly state what milestone must be achieved first (e.g., reaching $100k revenue for CanExport). 

### 5. Using the Executive Document Vault
The vault contains over 14 premium, Deloitte-style templates. 

**For Financial Models (.xlsx):**
- Click the download link to save the file to your computer.
- Open it in Excel. The first tab always includes **Guidance Notes** instructing you on how to use the model, common mistakes to avoid, and where to input your assumptions.

**For Narrative Documents (HTML/PDF):**
- Click the document link (e.g., IRAP Project Brief). It will open in a new, clean tab.
- This is an interactive web page, but it is **Print-Ready**.
- Press `Ctrl + P` (or Cmd + P on Mac). The web styling will disappear, and you will see a perfectly formatted, QTSI-branded document ready to be saved as a PDF or printed for meetings.

### 6. Verifying Official Information
At the bottom of the portal, you will find the **Official Resources** section. This contains direct links to government websites. Because grant criteria can change rapidly, always use these links to verify intake dates and eligibility before submitting an application.
